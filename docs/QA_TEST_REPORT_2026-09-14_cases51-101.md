## ข้อสังเกตเพิ่มเติม (นอกเหนือเคส 51–101 ที่ได้รับมอบหมาย)

ระหว่าง start backend เจอ log บรรทัดนี้ที่ stderr ตอน server เริ่มทำงาน (server ไม่ได้ crash — ยัง listen ที่ port 5000 ได้ปกติ):

```
API key does not start with "SG.".
```

เกิดจาก `backend/src/services/email.service.js` เรียก `sgMail.setApiKey(process.env.SENDGRID_API_KEY)` ที่ module-level โดย `SENDGRID_API_KEY` ว่างเปล่าใน `.env` ของเครื่องนี้ — สังเกตว่า `docs/ARCHITECTURE.md` เขียนไว้ว่าระบบอีเมลใช้ **Gmail SMTP** แต่โค้ดจริงใช้ **SendGrid** (`@sendgrid/mail`) ไม่ตรงกัน ควรตรวจสอบว่าเอกสารหรือโค้ดอันไหนคือของจริง แล้วปรับให้ตรงกัน — ไม่ได้ทดสอบเพิ่มเติมเพราะ AUTH-11 (ฟีเจอร์ลืมรหัสผ่านที่ใช้ email service นี้) อยู่ในเคส 1–50 ที่ทดสอบไปแล้วในรายงานฉบับ 25 ส.ค.
