# คู่มือใช้งานระบบ SDMS

**เอกสารนี้เขียนไว้สำหรับคนที่ไม่เคยใช้ระบบแบบนี้มาก่อนเลย** อ่านตั้งแต่ต้นจนจบแล้วใช้งานระบบได้จริง ไม่จำเป็นต้องมีความรู้ด้านคอมพิวเตอร์มาก่อน

SDMS คือระบบที่ใช้แทนสมุดบัญชี/ไฟล์ Excel ที่หอพักเคยใช้จดข้อมูลห้อง ผู้เช่า ค่าเช่า ค่าน้ำ-ไฟ และเรื่องแจ้งซ่อมต่างๆ — ทุกคนเข้าใช้งานผ่านเว็บเบราว์เซอร์ (Chrome, Safari ฯลฯ) บนคอมพิวเตอร์หรือมือถือก็ได้ ไม่ต้องติดตั้งโปรแกรมอะไรเพิ่ม

ระบบแบ่งผู้ใช้เป็น 2 แบบ แต่ละแบบเห็นหน้าจอคนละชุด:

- 🗝️ **ผู้ดูแลระบบ (แอดมิน)** — คือเจ้าของหรือคนบริหารหอพัก จัดการห้อง ผู้เช่า สัญญา บิล การเงิน และคำร้องต่างๆ ของทั้งหอพัก
- 🏠 **ผู้เช่า** — คือคนที่พักอาศัยอยู่ในหอพัก ดูบิลของตัวเอง ชำระเงิน แจ้งซ่อม และขอย้ายออกได้เอง

## ภาพรวม: ระบบนี้ทำงานอย่างไร

ก่อนจะเริ่มกดอะไรในระบบ ให้เข้าใจภาพรวมนี้ก่อน — จะช่วยให้เข้าใจว่าทำไมบางอย่างต้องทำก่อน-หลัง

หอพักทำงานเป็นวงจรซ้ำทุกเดือน แบบนี้เสมอ:

1. **มีห้องอยู่ในระบบ** — แอดมินเพิ่มห้องพักทั้งหมดของหอพักเข้าระบบไว้ก่อน (ทำครั้งเดียวตอนเริ่มต้น)
2. **มีคนมาเช่า** — แอดมินเพิ่มชื่อผู้เช่าเข้าระบบ หรือผู้เช่าสมัครเข้ามาเอง
3. **ทำสัญญาเช่า** — แอดมินผูกผู้เช่ากับห้องที่เขาอยู่ผ่านสัญญาเช่า พอทำสัญญาแล้วห้องจะเปลี่ยนสถานะเป็น "มีผู้เช่า" ทันที
4. **ทุกสิ้นเดือน จดเลขมิเตอร์** — แอดมินไปอ่านมิเตอร์ไฟฟ้า/น้ำประปาจริงที่ห้อง แล้วบันทึกเลขเข้าระบบ
5. **ออกบิล** — ระบบคำนวณค่าไฟ + ค่าน้ำ (จากเลขมิเตอร์ข้อ 4) รวมกับค่าเช่า ออกมาเป็นบิลให้อัตโนมัติ
6. **ผู้เช่าจ่ายเงิน** — ผู้เช่าเห็นบิลในระบบ โอนเงินตามช่องทางที่หอพักกำหนด แล้วแนบรูปสลิปแจ้งเข้ามาในระบบ
7. **แอดมินตรวจสอบและยืนยัน** — แอดมินดูสลิปที่แนบมา ถ้าถูกต้องกดยืนยัน บิลถึงจะปิดเป็น "ชำระแล้ว" จริง (ไม่ใช่ปิดเองอัตโนมัติทันทีที่ผู้เช่ากดส่ง)
8. วนกลับไปข้อ 4 ใหม่ทุกเดือน

พูดสั้นๆ คือ **ห้อง → ผู้เช่า → สัญญา → มิเตอร์ → บิล → จ่ายเงิน → ตรวจสอบ** เข้าใจลำดับนี้แล้วจะไม่งงว่าทำไมระบบไม่ยอมให้ข้ามขั้นตอน เช่น ออกบิลไม่ได้ถ้ายังไม่จดมิเตอร์ หรือสร้างสัญญาไม่ได้ถ้าห้องมีคนอยู่แล้ว

นอกจากวงจรหลักนี้ ยังมีเรื่องเสริมที่ทำได้ทุกเมื่อ ไม่ต้องรอรอบเดือน เช่น แจ้งซ่อม ประกาศข่าวสาร และขอย้ายออก

## เริ่มต้นใช้งานระบบสำหรับหอพักใหม่ (สำหรับแอดมิน)

ถ้าเพิ่งได้บัญชีแอดมินมาและหอพักยังไม่เคยใช้ระบบนี้มาก่อน **ให้ทำตามลำดับนี้** ในวันแรกที่เริ่มใช้งาน อย่าข้ามขั้นตอน เพราะแต่ละขั้นเป็นฐานของขั้นถัดไป

| ลำดับ | ทำอะไร | ทำที่เมนู |
|---|---|---|
| 1 | เปลี่ยนรหัสผ่านแอดมินตามที่ระบบบังคับตอนเข้าครั้งแรก | (อัตโนมัติตอนล็อกอินครั้งแรก) |
| 2 | ตั้งค่าพื้นฐานของหอพัก — ชื่อหอพัก, บัญชีธนาคาร/พร้อมเพย์สำหรับรับเงิน, อัตราค่าไฟ-ค่าน้ำ | [ตั้งค่า](#a12-ตั้งค่า) |
| 3 | เพิ่มห้องพักทั้งหมดที่หอพักมีเข้าระบบ | [ห้องพัก](#a02-ห้องพัก) |
| 4 | เพิ่มผู้เช่าที่อยู่แล้วในปัจจุบันเข้าระบบ (หรือให้เขาสมัครเองก็ได้) | [ผู้เช่า](#a03-ผู้เช่า) |
| 5 | สร้างสัญญาเช่าผูกผู้เช่าแต่ละคนกับห้องที่เขาอยู่ | [สัญญาเช่า](#a04-สัญญาเช่า) |
| 6 | (ถ้าอยากให้แจ้งเตือนอัตโนมัติผ่านมือถือ) ผูก Telegram Bot ของหอพัก | [ตั้งค่า](#a12-ตั้งค่า) |

หลังจากตั้งค่าครั้งแรกครบแล้ว **ทุกสิ้นเดือนจากนี้ทำวนซ้ำแค่ 3 ขั้นตอนนี้เท่านั้น**:

1. [บันทึกมิเตอร์](#a06-บันทึกมิเตอร์) ของทุกห้อง
2. [ออกบิล](#a07-บิล) ของทุกห้อง
3. [ตรวจสอบและยืนยันการชำระเงิน](#a08-การชำระเงิน) เมื่อผู้เช่าแจ้งโอนเข้ามา

ส่วนเรื่องอื่นๆ เช่นแจ้งซ่อม ประกาศ หรือคำร้องย้ายออก ทำได้ทุกเมื่อที่มีเรื่องเข้ามา ไม่ต้องรอรอบเดือน

## วิธีเข้าสู่ระบบ (ทั้งแอดมินและผู้เช่า)

1. เปิดเว็บเบราว์เซอร์ (เช่น Chrome) แล้วเข้าลิงก์เว็บของหอพัก จะเจอหน้าแรกเป็นหน้าเข้าสู่ระบบ
2. กรอกช่อง **เบอร์โทรศัพท์ หรือ อีเมล** ด้วยเบอร์โทร/อีเมลที่ผูกกับบัญชี
3. กรอกช่อง **รหัสผ่าน**
4. (ไม่บังคับ) ติ๊ก **จดจำฉัน** ถ้าไม่อยากให้ระบบตัดการเข้าสู่ระบบเร็วเกินไป
5. กดปุ่ม **เข้าสู่ระบบ**

✅ ระบบพาไปหน้าของแต่ละคนให้อัตโนมัติ (แอดมินไปหน้าแดชบอร์ดแอดมิน ผู้เช่าไปหน้าแดชบอร์ดผู้เช่า)

### ลืมรหัสผ่านทำอย่างไร

1. ที่หน้าเข้าสู่ระบบ กด **ลืมรหัสผ่าน?**
2. กรอกชื่อผู้ใช้ (เบอร์โทร/อีเมล) แล้วส่งคำขอ
3. เปิดอีเมลที่ผูกกับบัญชี จะมีอีเมลส่งลิงก์ตั้งรหัสผ่านใหม่มาให้ กดลิงก์นั้น
4. กรอกรหัสผ่านใหม่ 2 ช่องให้ตรงกัน แล้วยืนยัน

✅ ใช้รหัสผ่านใหม่เข้าสู่ระบบได้ทันที

### บัญชีแอดมิน — ทำไมต้องเปลี่ยนรหัสผ่านตอนเข้าครั้งแรก

บัญชีแอดมินจะถูกสร้างมาให้พร้อมรหัสผ่านตั้งต้น (ไม่มีหน้าสมัครสมาชิกสำหรับแอดมิน) เพื่อความปลอดภัย ระบบจะบังคับให้เปลี่ยนรหัสผ่านทันทีที่เข้าสู่ระบบครั้งแรก จะเข้าเมนูอื่นไม่ได้จนกว่าจะเปลี่ยนสำเร็จ:

1. เข้าสู่ระบบด้วยเบอร์/อีเมล + รหัสผ่านตั้งต้นที่ได้รับมาตามปกติ
2. ระบบพาไปหน้า **ต้องเปลี่ยนรหัสผ่านก่อนใช้งาน** ให้เองอัตโนมัติ
3. กรอกช่อง **รหัสผ่านตั้งต้น** (รหัสผ่านเดิมที่เพิ่งใช้เข้าสู่ระบบ)
4. กรอกช่อง **รหัสผ่านใหม่** ที่ต้องการใช้ต่อจากนี้ — มีแถบสีบอกความแข็งแรงของรหัสผ่านให้ดูสด ยิ่งเขียวยิ่งปลอดภัย
5. กรอกช่อง **ยืนยันรหัสผ่านใหม่** ให้ตรงกับข้อ 4
6. กด **เปลี่ยนรหัสผ่านและเข้าใช้งาน**

✅ เข้าสู่หน้าแดชบอร์ดแอดมินได้ทันที ครั้งต่อไปให้ใช้รหัสผ่านใหม่นี้เข้าสู่ระบบ (จำรหัสผ่านนี้ไว้ให้ดี ห้ามลืม)

### บัญชีผู้เช่า — สมัครได้ 2 แบบ

**แบบที่ 1: สมัครด้วยตัวเอง**

1. ที่หน้าเข้าสู่ระบบ กดลิงก์ **ยังไม่มีบัญชี? สมัครสมาชิก**
2. กรอก **ชื่อ-นามสกุล**
3. กรอก **เบอร์โทร** — จำเบอร์นี้ให้ดี เพราะจะใช้เป็นชื่อผู้ใช้สำหรับเข้าสู่ระบบทุกครั้งต่อจากนี้
4. กรอก **อีเมล**
5. ตั้ง **รหัสผ่าน** และกรอก **ยืนยันรหัสผ่าน** ให้ตรงกัน (ต้องยาวอย่างน้อย 6 ตัวอักษร)
6. กดปุ่มสมัครสมาชิก

✅ เข้าสู่ระบบได้ทันทีโดยไม่ต้องเข้าสู่ระบบซ้ำอีกรอบ — หรือถ้ามีบัญชี Google อยู่แล้ว กดปุ่ม **Google** แทนขั้นตอนทั้งหมดนี้ได้เลย เร็วกว่า

**แบบที่ 2: แอดมินสร้างบัญชีให้**

ถ้าแอดมินเป็นคนเพิ่มชื่อเข้าระบบให้ (ดูหัวข้อ [ผู้เช่า](#a03-ผู้เช่า)) ไม่ต้องสมัครเอง — แอดมินจะให้เบอร์โทรและรหัสผ่านมา นำมากรอกที่หน้าเข้าสู่ระบบได้เลยตามขั้นตอน "วิธีเข้าสู่ระบบ" ด้านบน

# ฝั่งแอดมิน

รายละเอียดของแต่ละเมนูในแถบด้านซ้ายของแอดมิน เรียงตามลำดับที่ปรากฏจริงในระบบ

## A01 แดชบอร์ด

หน้าแรกที่เจอทันทีหลังเข้าสู่ระบบ เป็นหน้าสรุปภาพรวม **ดูอย่างเดียว ไม่มีอะไรให้กรอก** — เปิดมาแล้วรู้ทันทีว่าวันนี้มีอะไรต้องจัดการบ้าง

- การ์ดสรุป 4 ตัว: จำนวนห้องพัก (มีผู้เช่า/ทั้งหมด), จำนวนผู้เช่า, ยอดเงินที่ยังค้างชำระอยู่, ยอดเงินที่เก็บได้สะสม
- แถบเตือนถ้ามีบิลเกินกำหนดชำระ หรือมีเรื่องแจ้งซ่อมที่ยังไม่ได้จัดการ — กด **ดูทั้งหมด** เพื่อไปดูรายการเต็ม
- รายการบิลล่าสุด และรายการแจ้งซ่อมล่าสุด ให้ดูคร่าวๆ
- ผังห้องพักเป็นสีบอกสถานะห้อง (ว่าง/มีผู้เช่า/ซ่อมบำรุง) — กดที่ห้องไหนก็ได้เพื่อไปหน้ารายละเอียดห้องนั้นทันที

## A02 ห้องพัก

ทะเบียนห้องทั้งหมดของหอพัก — **ต้องเพิ่มห้องเข้าระบบก่อนถึงจะสร้างสัญญาเช่าให้ผู้เช่าได้** ค้นหาด้วยเลขห้อง หรือกรองตามสถานะ (ว่าง / มีผู้เช่า / ซ่อมบำรุง) ได้ที่แถบด้านบนตาราง

### วิธีเพิ่มห้องพักใหม่

1. เข้าเมนู **ห้องพัก** ทางแถบซ้าย
2. กดปุ่ม **+ เพิ่มห้องพัก** มุมขวาบน
3. เลือก **ชั้น** ก่อน — ระบบจะช่วยเดา**เลขห้อง**ที่ยังว่างให้อัตโนมัติ แก้เป็นเลขอื่นได้ถ้าต้องการ
4. เลือก **ประเภทห้อง** — ห้องพัดลม หรือ ห้องแอร์
5. ตั้ง **สถานะ** เริ่มต้น (ห้องใหม่ที่ยังไม่มีคนอยู่ให้เลือก "ว่าง")
6. กรอก **ค่าเช่า** ต่อเดือน
7. กรอก **พื้นที่ (ตร.ม.)** และ **หมายเหตุ** เพิ่มเติมได้ตามต้องการ (ไม่บังคับ)
8. กดปุ่ม **บันทึก**

✅ ห้องใหม่ขึ้นในตารางทันที พร้อมให้เลือกตอนสร้างสัญญาเช่าต่อไป

### วิธีแก้ไขข้อมูลห้อง

1. หาห้องที่ต้องการในตาราง (พิมพ์เลขห้องในช่องค้นหาช่วยหาได้เร็วขึ้น)
2. กดไอคอนรูปดินสอ (แก้ไข) ที่แถวนั้น
3. แก้ไขค่าที่ต้องการ เช่น ค่าเช่า สถานะ หรือหมายเหตุ
4. กด **บันทึก**

### วิธีลบห้องพัก

1. กดไอคอนรูปถังขยะ (ลบ) ที่แถวห้องนั้น
2. ยืนยันการลบในกล่องที่ขึ้นมา

> ⚠️ **ลบห้องไม่ได้ถ้าสถานะเป็น "มีผู้เช่า" อยู่** ต้องไปยกเลิกสัญญาที่เมนู [สัญญาเช่า](#a04-สัญญาเช่า) ก่อน ระบบจะเปลี่ยนสถานะห้องเป็นว่างให้เองหลังยกเลิกสัญญา แล้วค่อยกลับมาลบห้องได้

## A03 ผู้เช่า

ทะเบียนผู้เช่าทั้งหมดของหอพัก ค้นหาและกรองตามสถานะสัญญา (ทั้งหมด/มีสัญญาอยู่/ไม่มีสัญญา) ได้ที่แถบด้านบน

### วิธีเพิ่มผู้เช่าใหม่ (แอดมินสร้างบัญชีให้)

ใช้วิธีนี้เวลาผู้เช่าไม่สะดวกสมัครเอง — แอดมินกรอกข้อมูลให้แล้วยกเบอร์โทร/รหัสผ่านไปให้ผู้เช่าใช้เข้าสู่ระบบเอง

1. เข้าเมนู **ผู้เช่า** แล้วกดปุ่ม **+ เพิ่มผู้เช่า**
2. กรอก **ชื่อ** และ **นามสกุล**
3. กรอก **เบอร์โทร** — เบอร์นี้จะกลายเป็นชื่อผู้ใช้ที่ผู้เช่าใช้เข้าสู่ระบบ (จำไว้ให้แม่นก่อนยกให้ผู้เช่า)
4. กรอก **อีเมล** (ไม่บังคับ)
5. กรอก **เลขบัตรประชาชน 13 หลัก**
6. กรอกชื่อและเบอร์ **ผู้ติดต่อฉุกเฉิน** ของผู้เช่า (แนะนำให้กรอกไว้เผื่อจำเป็น)
7. ตั้ง **รหัสผ่าน** — ถ้าคิดไม่ออกว่าจะตั้งรหัสผ่านอะไร กดปุ่มรูปลูกเต๋าข้างช่องให้ระบบสุ่มรหัสผ่านที่ปลอดภัยให้แทนได้
8. กด **บันทึก**

✅ ผู้เช่าคนใหม่ขึ้นในตารางทันที **สำคัญ:** จดเบอร์โทรกับรหัสผ่านที่ตั้งไว้ แล้วส่งให้ผู้เช่าไปเข้าสู่ระบบเอง จากนั้นแอดมินไปสร้างสัญญาเช่าผูกกับห้องต่อได้ที่ [สัญญาเช่า](#a04-สัญญาเช่า)

### วิธีแก้ไขข้อมูลผู้เช่า

1. กดไอคอนแก้ไขที่แถวผู้เช่าคนนั้น
2. แก้ชื่อ นามสกุล อีเมล เบอร์โทร หรือผู้ติดต่อฉุกเฉินตามต้องการ
3. กด **บันทึก**

(หน้าแก้ไขจะไม่มีช่องเลขบัตรประชาชนและรหัสผ่านให้แก้ตรงนี้ — เลขบัตรจะแสดงแบบปิดบางส่วนในตารางเพื่อความปลอดภัยของผู้เช่า)

### วิธีลบผู้เช่า

1. กดไอคอนลบที่แถวผู้เช่าคนนั้น
2. ยืนยันการลบ

> ⚠️ **ลบผู้เช่าไม่ได้ถ้ายังมีสัญญาที่ใช้งานอยู่** ต้องไปยกเลิกสัญญาที่เมนู [สัญญาเช่า](#a04-สัญญาเช่า) ก่อน

## A04 สัญญาเช่า

จุดที่ผูก "ผู้เช่า" เข้ากับ "ห้อง" อย่างเป็นทางการ มีการ์ดสรุปด้านบนบอก: รวมทั้งหมด / ใช้งานอยู่ / หมดอายุหรือยกเลิก / รวมเงินประกันที่ถืออยู่ทั้งหมด

### วิธีสร้างสัญญาเช่าใหม่

ทำตอนที่ผู้เช่าเข้าอยู่ห้องจริงแล้วเท่านั้น — **ต้องมีทั้งชื่อผู้เช่าในระบบ (จาก A03) และห้องที่สถานะว่างอยู่ (จาก A02) ก่อน** ถึงจะทำขั้นตอนนี้ได้

1. เข้าเมนู **สัญญาเช่า** แล้วกดปุ่ม **+ สร้างสัญญาเช่าใหม่**
2. **เลือกผู้เช่า** จากรายชื่อที่มีอยู่ในระบบ
3. **เลือกห้อง** — ในช่องนี้จะโชว์เฉพาะห้องที่สถานะ "ว่าง" เท่านั้น (ห้องที่มีคนอยู่แล้วจะไม่ขึ้นให้เลือก) พอเลือกห้องแล้ว ค่าเช่าจะดึงมาให้อัตโนมัติ
4. เลือก **วันเริ่มต้น** และ **วันสิ้นสุด** ของสัญญา
5. แก้ไขตัวเลข **ค่าเช่า** ได้ถ้าต้องการคิดราคาต่างจากค่าเช่าปกติของห้อง
6. กรอกจำนวน **เงินประกัน** ที่เก็บจากผู้เช่า
7. ถ้ามีไฟล์สัญญาที่พิมพ์/สแกนไว้แล้ว แนบเข้าไปที่ **ไฟล์สัญญา** (รองรับ PDF หรือ Word) — ไม่บังคับ แต่ถ้าแนบไว้ ผู้เช่าจะดาวน์โหลดดูเองได้ทีหลัง
8. กรอก **หมายเหตุ** เพิ่มเติมได้ถ้ามี
9. กด **บันทึก**

✅ สัญญาสถานะ "ใช้งานอยู่" ถูกสร้างขึ้น ห้องที่เลือกจะเปลี่ยนสถานะเป็น "มีผู้เช่า" ให้อัตโนมัติทันที

### วิธียกเลิกสัญญา (เมื่อผู้เช่าย้ายออก)

1. เปิดดูรายละเอียดสัญญาที่สถานะ "ใช้งานอยู่" ของผู้เช่าคนนั้น
2. กด **ยกเลิกสัญญา**
3. ระบุเหตุผลและยืนยันในกล่องที่ขึ้นมา

✅ สัญญาเปลี่ยนเป็นสถานะยกเลิก ห้องจะกลับมาว่างพร้อมให้คนอื่นเช่าต่อ ขั้นตอนถัดไปคือไปเคลียร์เงินประกันคืนที่เมนู [คำร้องย้ายออก](#a05-คำร้องย้ายออก)

### วิธีต่อสัญญาเช่า (เมื่อผู้เช่าอยู่ต่อ ไม่ย้ายออก)

1. เปิดดูรายละเอียดสัญญาที่สถานะ "หมดอายุ"
2. กด **ต่อสัญญา**
3. เลือก **วันสิ้นสุดใหม่**
4. ปรับ **ค่าเช่า** ใหม่ได้ถ้าจะขึ้นราคา (ไม่บังคับ ปล่อยว่างไว้ = ใช้ราคาเดิม)
5. กดยืนยัน

✅ สัญญากลับมาเป็นสถานะ "ใช้งานอยู่" และห้องกลับเป็น "มีผู้เช่า" ให้อัตโนมัติ ไม่ต้องสร้างสัญญาใหม่ทั้งฉบับ

## A05 คำร้องย้ายออก

หน้ารวมคำร้องที่ผู้เช่ายื่นเข้ามาขอย้ายออก กรองตามสถานะ (รอพิจารณา / อนุมัติแล้ว / ไม่อนุมัติ) ได้ที่แถบด้านบน

### วิธีพิจารณาคำร้องย้ายออก

1. เปิดคำร้องที่สถานะ "รอพิจารณา" — จะเห็นวันที่ผู้เช่าต้องการย้ายออกและเหตุผลที่เขาระบุ
2. ถ้าเห็นด้วยให้ย้ายออกได้ กด **อนุมัติ**
3. ถ้าไม่อนุมัติ กด **ไม่อนุมัติ** แล้ว **ระบุเหตุผล** ที่ปฏิเสธ (ต้องกรอกเสมอ ผู้เช่าจะเห็นเหตุผลนี้) ก่อนยืนยัน

### วิธีเคลียร์เงินประกันคืนหลังอนุมัติให้ย้ายออก

หลังอนุมัติคำร้องแล้ว ต้องมาคำนวณว่าจะคืนเงินประกันให้ผู้เช่าเท่าไหร่:

1. เปิดคำร้องที่อนุมัติแล้ว แล้วเข้าสู่ขั้นตอนเคลียร์ยอด
2. กรอก **วันที่ย้ายออกจริง**
3. กรอก **เลขมิเตอร์น้ำ-ไฟ เริ่มต้น/สิ้นสุด** ของงวดสุดท้ายก่อนย้ายออก (เพื่อคิดเป็นค่าน้ำ-ไฟงวดสุดท้าย)
4. กรอก **ค่าเสียหาย** ถ้าห้องมีของเสียหายที่ต้องหักจากเงินประกัน (ไม่มีก็เว้นว่าง)
5. ใส่ **หมายเหตุ** เพิ่มเติมได้
6. ตรวจ **ยอดคืนสุทธิ** ที่ระบบคำนวณให้อัตโนมัติ (เงินประกัน − ค่าน้ำ-ไฟงวดสุดท้าย − ค่าเสียหาย)
7. ยืนยันการเคลียร์ยอด

✅ ระบบจะบอกผลลัพธ์ให้ชัดเจนว่าต้อง **"คืนเงินผู้เช่า"** เท่าไหร่ หรือถ้ายอดหักลบติดลบ จะกลายเป็น **"ผู้เช่าต้องจ่ายเพิ่ม"** แทน

## A06 บันทึกมิเตอร์

จุดที่แอดมินบันทึกเลขมิเตอร์ไฟฟ้า/น้ำประปาที่อ่านได้จริงจากห้อง **ต้องทำขั้นตอนนี้ก่อนเสมอ ถึงจะไปออกบิลของเดือนนั้นได้** ค้นหาด้วยเลขห้องหรือกรองตามเดือนได้ที่แถบด้านบน

### วิธีบันทึกมิเตอร์ประจำเดือน

1. เข้าเมนู **บันทึกมิเตอร์** แล้วกดปุ่ม **+ บันทึกมิเตอร์**
2. **เลือกห้อง** และ **เดือน/ปี** ที่จะบันทึก
3. ช่องไฟฟ้า: กรอก **เลขก่อนหน้า** (ปกติระบบดึงจากเดือนก่อนมาให้อัตโนมัติ ไม่ต้องหาเอง) และ **เลขปัจจุบัน** ที่อ่านได้จริงจากมิเตอร์
4. ถ่ายรูปมิเตอร์เก็บไว้เป็นหลักฐานได้ที่ช่อง **รูปมิเตอร์ไฟฟ้า** (ไม่บังคับ แต่แนะนำให้ถ่ายไว้กันปัญหาโต้แย้งทีหลัง)
5. ทำแบบเดียวกันกับช่องน้ำประปา — ยกเว้นถ้าหอพักตั้งค่าน้ำเป็น "เหมาจ่าย" ไว้แล้ว (ดูหัวข้อ [ตั้งค่า](#a12-ตั้งค่า)) จะไม่มีช่องนี้ให้กรอกเลย ระบบคิดค่าน้ำคงที่ให้อัตโนมัติ
6. กด **บันทึกมิเตอร์**

✅ ค่ามิเตอร์ของห้องนี้เดือนนี้พร้อมนำไปออกบิลที่เมนู [บิล](#a07-บิล) แล้ว

> ⚠️ ข้อควรระวัง: เลขปัจจุบันต้อง**มากกว่าหรือเท่ากับ**เลขก่อนหน้าเสมอ (มิเตอร์เดินไปข้างหน้าเรื่อยๆ ไม่มีทางถอยหลัง), ห้ามบันทึกซ้ำเดือนเดิมของห้องเดิมสองครั้ง, และห้องนั้นต้องมีสัญญาเช่าที่ใช้งานอยู่ก่อนถึงจะบันทึกได้

## A07 บิล

จุดออกใบแจ้งหนี้ประจำเดือนของแต่ละห้อง สถานะบิลที่จะเจอ: **ยังไม่ชำระ** (เพิ่งออก รอผู้เช่าจ่าย) / **ชำระแล้ว** (แอดมินยืนยันการจ่ายแล้ว) / **เกินกำหนด** (เลยวันครบกำหนดจ่ายไปแล้วยังไม่จ่าย) / **ยกเลิก**

### วิธีออกบิล

1. ต้องบันทึกมิเตอร์ของห้องและเดือนนั้นให้เรียบร้อยก่อนที่เมนู [บันทึกมิเตอร์](#a06-บันทึกมิเตอร์) (ถ้ายังไม่ได้บันทึก ระบบจะเตือนให้ไปทำก่อนอยู่ดี)
2. เข้าเมนู **บิล** แล้วกดปุ่ม **+ สร้างบิล**
3. เลือก **ห้อง** และ **เดือน/ปี**
4. ระบบคำนวณยอดรวมให้อัตโนมัติจาก ค่าไฟฟ้า + ค่าน้ำ (คิดจากเลขมิเตอร์ที่บันทึกไว้) + ค่าเช่า + ค่าอื่นๆ (ถ้ามี) — ตรวจดูยอดให้ถูกต้องก่อนบันทึกจริง
5. ตั้ง **วันกำหนดชำระ** ว่าผู้เช่าต้องจ่ายภายในวันไหน
6. กด **สร้างบิล**

✅ บิลสถานะ "ยังไม่ชำระ" ขึ้นในตารางทันที และผู้เช่าจะเห็นบิลนี้ที่หน้าแดชบอร์ดกับหน้า "บิลของฉัน" ฝั่งของเขาทันทีเช่นกัน

### วิธีดาวน์โหลดใบแจ้งหนี้ / ยกเลิกบิลที่ออกผิด

1. หาบิลที่ต้องการในตาราง
2. กดไอคอนดาวน์โหลดเพื่อได้ไฟล์ PDF ใบแจ้งหนี้ ไว้พิมพ์หรือส่งให้ผู้เช่าดูนอกระบบก็ได้
3. ถ้าออกบิลผิด กด **ยกเลิกบิล** แล้วยืนยัน

> ⚠️ ออกบิลไม่ได้ถ้า: ห้องนั้นยังไม่มีสัญญาเช่าที่ใช้งานอยู่, ยังไม่ได้บันทึกมิเตอร์ของเดือนนั้น, หรือออกบิลของเดือนนั้นไปแล้วก่อนหน้านี้

## A08 การชำระเงิน

คิวตรวจสอบการแจ้งชำระเงินที่ผู้เช่าส่งเข้ามารอให้แอดมินตรวจและยืนยัน **ขั้นตอนนี้สำคัญมาก** เพราะบิลจะไม่ปิดเป็น "ชำระแล้ว" เองอัตโนมัติ ต้องรอแอดมินกดยืนยันก่อนเท่านั้น

### วิธียืนยัน / ปฏิเสธการชำระเงิน

1. เปิดรายการที่รอตรวจสอบ — ดูว่าผู้เช่าเลือกจ่ายด้วยวิธีไหน (พร้อมเพย์ / เงินสด / โอนเงิน)
2. กด **ดูรูปขนาดเต็ม** เพื่อตรวจสลิปโอนเงินให้ชัดเจน (ถ้าจ่ายเงินสดจะไม่มีรูปสลิปให้ดู)
3. เทียบยอดเงินในสลิปกับยอดบิลให้ตรงกัน
4. ถ้าถูกต้องครบถ้วน กด **ยืนยัน**
5. ถ้าสลิปผิดหรือยอดไม่ตรง กด **ปฏิเสธ** แล้ว **ระบุเหตุผล** ที่ปฏิเสธ (ต้องกรอกเสมอ) ก่อนยืนยัน

✅ กดยืนยันแล้ว บิลที่เกี่ยวข้องจะเปลี่ยนเป็น "ชำระแล้ว" ทันที ส่วนถ้าปฏิเสธ ผู้เช่าจะเห็นเหตุผลที่ถูกปฏิเสธ และแจ้งชำระเงินเข้ามาใหม่ได้อีกครั้ง

## A09 ประวัติการชำระเงิน

หน้ารวมประวัติการชำระเงินทั้งหมดของหอพักทุกห้องทุกเดือน ทั้งที่ยืนยันแล้วและที่ถูกปฏิเสธ ย้อนดูรูปสลิปเก่าได้ทุกรายการ ใช้เก็บหลักฐานหรือตรวจสอบย้อนหลังได้

### วิธีส่งออกรายงานเป็นไฟล์ Excel

1. เลือกช่วงวันที่ที่ต้องการดึงข้อมูล
2. กดปุ่ม **Export Excel**
3. ถ้าในช่วงที่เลือกมีรายการที่ยังไม่ได้ยืนยันปนอยู่ ระบบจะเตือนก่อน — เลือกยืนยันต่อได้ถ้าต้องการรวมรายการนั้นไปด้วย

## A10 แจ้งซ่อม

หน้ารวมคำร้องแจ้งซ่อมจากผู้เช่าทุกห้อง ทำได้ทุกเมื่อไม่ต้องรอรอบเดือน ค้นหาและกรองตามสถานะได้ที่แถบด้านบน

### วิธีมอบหมายงานซ่อมและอัปเดตความคืบหน้า

1. เปิดคำร้องที่ต้องการจัดการ — จะเห็นหมวดหมู่ปัญหา ระดับความสำคัญ รายละเอียดที่ผู้เช่าเขียน และรูปที่แนบมา (ถ้ามี)
2. เลือกช่อง **มอบหมายให้** แล้วเลือกชื่อแอดมิน/ช่างที่จะรับผิดชอบงานนี้ (เลือกได้จากรายชื่อแอดมินที่ยัง active อยู่ในระบบเท่านั้น)
3. ใส่ **หมายเหตุแอดมิน** เพิ่มเติมได้ถ้ามีข้อมูลอยากบันทึกไว้
4. เปลี่ยน **สถานะ** คำร้องให้ตรงกับความคืบหน้าจริง (เช่น เปลี่ยนจาก "รอดำเนินการ" เป็น "กำลังดำเนินการ" แล้วค่อยเปลี่ยนเป็น "เสร็จสิ้น" ทีหลัง)
5. บันทึก

✅ ทุกครั้งที่มีการอัปเดตสถานะ ผู้เช่าเจ้าของคำร้องจะได้รับแจ้งเตือนผ่าน Telegram ให้อัตโนมัติ (ถ้าเขาเชื่อมต่อ Telegram ไว้และไม่ได้ปิดการแจ้งเตือน) และเห็นชื่อคนที่รับผิดชอบเรื่องนี้ในหน้าคำร้องของตัวเองทันที

## A11 ประกาศ

จุดส่งข่าวสาร/ประกาศไปถึงผู้เช่าและ/หรือแอดมินด้วยกันเอง เช่น แจ้งซ่อมท่อประปารวม แจ้งวันหยุด แจ้งกฎระเบียบใหม่

### วิธีสร้างประกาศ

1. เข้าเมนู **ประกาศ** แล้วกด **+ สร้างประกาศ**
2. กรอก **หัวข้อประกาศ** และ **เนื้อหา** รายละเอียด
3. เลือก **กลุ่มเป้าหมาย** — จะส่งถึงทุกคน หรือผู้เช่าเท่านั้น หรือแอดมินเท่านั้น
4. ถ้าอยากให้เห็นเฉพาะบางชั้น เลือก **กรองเฉพาะชั้น** ได้ (ไม่บังคับ)
5. เปิด **ปักหมุด** ถ้าอยากให้ประกาศนี้อยู่บนสุดของฟีดตลอด ไม่ถูกประกาศใหม่ดันตกไป
6. ตั้ง **วันหมดอายุ** ถ้าอยากให้ประกาศหายไปเองอัตโนมัติหลังถึงวันนั้น (ไม่บังคับ)
7. เปิด **ประกาศฉุกเฉิน** ถ้าเป็นเรื่องด่วนมากๆ (ระบบจะเน้นสีให้เห็นเด่นชัดกว่าประกาศทั่วไป)
8. เปิด **ส่งผ่าน Telegram** ถ้าอยากให้ข้อความนี้ส่งเข้าไปในแชท Telegram ของผู้เช่าด้วย — จะมีแท็บพรีวิวให้ดูก่อนว่าข้อความที่จะส่งจริงหน้าตาเป็นอย่างไร ก่อนกดส่งจริง
9. กด **บันทึก/เผยแพร่**

✅ ประกาศขึ้นบนฟีดของกลุ่มเป้าหมายที่เลือกทันที

## A12 ตั้งค่า

ศูนย์รวมการตั้งค่าพื้นฐานของหอพักทั้งหมด **ควรเข้ามาตั้งค่าส่วนนี้ให้เรียบร้อยตั้งแต่วันแรกที่เริ่มใช้ระบบ** แบ่งเป็น 4 แท็บ: **ทั่วไป** · **การเงิน** · **แจ้งเตือน** · **ความปลอดภัย**

### วิธีตั้งอัตราค่าไฟ-ค่าน้ำ

ค่านี้สำคัญมาก เพราะเป็นฐานคำนวณบิลของทุกห้องทุกเดือน แก้ตรงนี้ทีเดียวมีผลกับบิลรอบถัดไปทั้งหมดทันที:

1. เข้าแท็บ **การเงิน**
2. กรอก **ค่าไฟ (บาท/หน่วย)** ตามที่หอพักกำหนด
3. เลือกรูปแบบคิดค่าน้ำ — **คิดตามหน่วยมิเตอร์** (ต้องจดเลขมิเตอร์น้ำทุกเดือน) หรือ **เหมาจ่ายคงที่** (จ่ายเท่ากันทุกเดือน ไม่ต้องจดมิเตอร์น้ำเลย)
4. ถ้าเลือกเหมาจ่าย กรอกยอดคงที่ต่อเดือน
5. กด **บันทึก**

### วิธีตั้งบัญชีรับเงิน (ธนาคาร/พร้อมเพย์)

1. ในแท็บ **การเงิน** เดียวกัน กรอก **ชื่อธนาคาร**, **เลขบัญชี**, **ชื่อบัญชี** ที่ใช้รับโอนเงินค่าเช่า
2. เลือกประเภทพร้อมเพย์ — จะผูกกับ **เบอร์โทร** หรือ **เลขบัตรประชาชน**
3. กรอกหมายเลขพร้อมเพย์ตามประเภทที่เลือก
4. กด **บันทึก**

✅ ผู้เช่าจะเห็นข้อมูลนี้เป็น QR โค้ดพร้อมเพย์และเลขบัญชีตอนแจ้งชำระเงินที่หน้า [ชำระเงิน](#t03-ชำระเงิน) ของเขา

### วิธีผูก Telegram Bot ของหอพัก (ไม่บังคับ แต่แนะนำ)

การผูก Telegram ทำให้ผู้เช่าและแอดมินได้รับแจ้งเตือนอัตโนมัติผ่านมือถือ โดยไม่ต้องเปิดเว็บเช็คเอง:

1. เข้าแท็บ **แจ้งเตือน**
2. เริ่มแชทกับ Telegram Bot ของระบบตามลิงก์ที่หน้าจอให้ไว้
3. ส่งคำสั่งผูกบัญชีตามที่หน้าจอบอก
4. คัดลอกรหัสแชท (chat ID) ที่บอทตอบกลับมา
5. วางรหัสนั้นลงในช่องที่หน้าตั้งค่า แล้วบันทึก

✅ ผูกสำเร็จแล้ว ลองใช้ช่องส่งข้อความกระจายเสียงในแท็บเดียวกันทดสอบส่งข้อความถึงทุกคนดูได้ทันที

### วิธีเปิด/ปิดการแจ้งเตือนอัตโนมัติ

1. ในแท็บ **แจ้งเตือน** เลื่อนสวิตช์ตรง แจ้งเตือนการชำระเงิน / แจ้งเตือนแจ้งซ่อม / แจ้งเตือนเกินกำหนด ตามที่ต้องการเปิดหรือปิด
2. บันทึก

### วิธีเปลี่ยนรหัสผ่านแอดมิน

1. เข้าแท็บ **ความปลอดภัย**
2. กรอก **รหัสผ่านเดิม**
3. กรอก **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่**
4. กดบันทึก

## A13 โปรไฟล์

หน้าแก้ไขข้อมูลส่วนตัวของบัญชีแอดมินที่กำลังใช้งานอยู่

### วิธีแก้ไขข้อมูลส่วนตัว

1. เข้าเมนู **โปรไฟล์** ที่ท้าย sidebar ด้านซ้ายมือ
2. แก้ชื่อ นามสกุล หรือข้อมูลติดต่อ
3. กดบันทึก — หรือเปลี่ยนรหัสผ่านตัวเองได้ในหน้าเดียวกันเลย (ขั้นตอนแบบเดียวกับแท็บความปลอดภัยใน [A12 ตั้งค่า](#a12-ตั้งค่า))

# ฝั่งผู้เช่า

## สิ่งที่ผู้เช่าใหม่ควรรู้ก่อนเริ่มใช้งาน

ถ้าเพิ่งย้ายเข้าหอพักและได้บัญชีมาใหม่ อ่านส่วนนี้ก่อนเพื่อเข้าใจว่าต้องใช้ระบบยังไงในชีวิตประจำวัน

**รอบการใช้งานปกติของผู้เช่าในแต่ละเดือน:**

1. รอแอดมินออกบิลค่าเช่า+ค่าน้ำ-ค่าไฟของเดือนนั้น (จะเห็นแจ้งเตือนที่หน้าแดชบอร์ดทันทีที่บิลออก)
2. เข้าไปดูยอดที่ต้องจ่ายที่เมนู [บิลของฉัน](#t02-บิลของฉัน)
3. โอนเงินตามช่องทางที่หอพักกำหนด แล้วแจ้งชำระเงินพร้อมแนบสลิปที่เมนู [ชำระเงิน](#t03-ชำระเงิน)
4. รอแอดมินตรวจสลิปและกดยืนยัน — เมื่อยืนยันแล้วบิลจะขึ้นสถานะ "ชำระแล้ว" (ระหว่างรอจะเห็นสถานะ "รอตรวจสอบ")

**เรื่องอื่นๆ ที่ทำได้ทุกเมื่อ ไม่ต้องรอรอบเดือน:**

- ห้องมีปัญหา (น้ำรั่ว ไฟดับ เครื่องใช้ไฟฟ้าเสีย ฯลฯ) → แจ้งซ่อมได้เองที่เมนู [ขอซ่อมแซม](#t06-ขอซ่อมแซม)
- จะย้ายออกจากหอพัก → ยื่นคำร้องล่วงหน้าได้เองที่เมนู [ขอย้ายออก](#t07-ขอย้ายออก)
- อยากดูรายละเอียดสัญญาเช่า หรือดาวน์โหลดไฟล์สัญญา → เมนู [สัญญาเช่า](#t05-สัญญาเช่า)

แนะนำให้เข้าไปเชื่อมต่อ Telegram ที่เมนู [โปรไฟล์](#t09-โปรไฟล์) ไว้ตั้งแต่แรก จะได้รับแจ้งเตือนบิลใหม่และผลแจ้งซ่อมทางมือถือทันที ไม่ต้องคอยเปิดเว็บเช็คเอง

## T01 แดชบอร์ด

หน้าแรกหลังเข้าสู่ระบบ ทักทายด้วยชื่อผู้เช่า พร้อมสรุปสิ่งที่ต้องรู้ทันที **ดูอย่างเดียว ไม่มีอะไรให้กรอก**

- การ์ดห้องพักที่พักอยู่ และค่าเช่ารายเดือน
- ยอดบิลล่าสุดที่ต้องชำระ พร้อมปุ่ม **ชำระเงิน** กดจ่ายได้ทันทีจากตรงนี้
- ป้ายเตือน "บิลเกินกำหนดชำระ!" สีแดงถ้ามีบิลค้างจ่ายเลยกำหนด หรือข้อความ "ไม่มียอดค้างชำระ" สีเขียวถ้าจ่ายครบแล้ว

## T02 บิลของฉัน

รายการบิลทั้งหมดของห้องตัวเอง ทั้งบิลเก่าและบิลปัจจุบัน

### วิธีดูใบแจ้งหนี้และไปชำระเงิน

1. เข้าเมนู **บิลของฉัน**
2. กดที่บิลที่ต้องการดูรายละเอียด (จะเห็นค่าเช่า ค่าไฟ ค่าน้ำ แยกรายการให้ดูชัดเจน)
3. กด **ชำระบิลนี้**

✅ ระบบพาไปหน้า [ชำระเงิน](#t03-ชำระเงิน) พร้อมเลือกบิลนี้ไว้ให้แล้วโดยอัตโนมัติ

## T03 ชำระเงิน

หน้าแจ้งชำระเงินให้แอดมินตรวจสอบ — **แค่แจ้งเข้ามาเท่านั้น ยังไม่ถือว่าจ่ายเสร็จสมบูรณ์จนกว่าแอดมินจะยืนยัน**

### วิธีแจ้งชำระเงิน

1. เข้าเมนู **ชำระเงิน**
2. **เลือกบิล** ที่จะจ่าย — เลือกได้มากกว่า 1 ใบพร้อมกันถ้ามีบิลค้างหลายเดือน ระบบจะรวมเป็น **ยอดค้างชำระ** เดียวให้เอง
3. เลือก **วิธีการชำระเงิน** — QR พร้อมเพย์ / เงินสด / โอนเงิน
4. ถ้าเลือกวิธีที่ไม่ใช่เงินสด: โอนเงินจริงตามช่องทางที่แสดงบนหน้าจอ (เลขบัญชี/QR โค้ด) แล้วกด **แนบสลิป** เพื่ออัปโหลดรูปหลักฐานการโอนที่เพิ่งทำ
5. ตรวจ **ยอดหลังชำระ** ที่หน้าสรุปให้ตรงกับที่โอนจริง
6. กด **ยืนยันการชำระเงิน**

✅ รายการขึ้นสถานะ "รอตรวจสอบ" ที่หน้า [ประวัติการชำระเงิน](#t04-ประวัติการชำระเงิน) — บิลจะเปลี่ยนเป็น "ชำระแล้ว" ก็ต่อเมื่อแอดมินตรวจสอบและกดยืนยันแล้วเท่านั้น ไม่ใช่ปิดทันทีที่กดส่ง อาจต้องรอสักพัก

> ⚠️ ต้องแนบสลิปทุกครั้งที่เลือกวิธีชำระเงินแบบอื่น ยกเว้นเลือกจ่ายด้วย **เงินสด** เท่านั้นที่ไม่ต้องแนบสลิป (เพราะจ่ายให้แอดมินโดยตรง)

## T04 ประวัติการชำระเงิน

ประวัติการชำระเงินของตัวเองทั้งหมดที่เคยแจ้งเข้ามา พร้อมสถานะปัจจุบันของแต่ละรายการ (รอตรวจสอบ / ยืนยันแล้ว / ถูกปฏิเสธ) — กดที่รายการเพื่อดูรูปสลิปย้อนหลังได้ ถ้ารายการไหนถูกปฏิเสธ จะเห็นเหตุผลที่แอดมินระบุไว้ด้วย เอาไว้แก้ไขแล้วแจ้งชำระใหม่ได้

## T05 สัญญาเช่า

ดูรายละเอียดสัญญาเช่าปัจจุบันของตัวเอง — วันเริ่มต้น/สิ้นสุดสัญญา ค่าเช่า เงินประกันที่วางไว้

### วิธีดาวน์โหลดไฟล์สัญญา

1. เข้าเมนู **สัญญาเช่า**
2. กด **ดาวน์โหลดสัญญา**

ปุ่มนี้จะกดได้เฉพาะตอนที่แอดมินแนบไฟล์สัญญาไว้ตอนสร้างสัญญาให้เท่านั้น — ถ้ายังไม่มีไฟล์ หน้านี้จะแสดงข้อความ "ยังไม่มีไฟล์สัญญา" แทน ให้ติดต่อแอดมินโดยตรงถ้าต้องการไฟล์

## T06 ขอซ่อมแซม

หน้าแจ้งปัญหาที่ต้องการให้ซ่อมและติดตามความคืบหน้า ทำได้ทุกเมื่อ

### วิธีส่งคำขอแจ้งซ่อม

1. เข้าเมนู **ขอซ่อมแซม** แล้วกด **ส่งคำขอใหม่**
2. เลือก **หมวดหมู่** ของปัญหา (เช่น ไฟฟ้า ประปา เครื่องใช้ไฟฟ้า)
3. กรอก **รายละเอียด** อธิบายปัญหาที่พบให้ชัดเจน
4. เลือกระดับ **ความสำคัญ** ของปัญหา
5. แนบรูปถ่ายปัญหาได้ (ไม่บังคับ แต่ช่วยให้ช่างเข้าใจปัญหาได้เร็วขึ้น)
6. กดส่งคำขอ

✅ คำขอขึ้นในรายการของตัวเองพร้อมสถานะ "รอดำเนินการ" — พอแอดมินมอบหมายงานให้ช่างแล้ว จะเห็นชื่อผู้รับผิดชอบขึ้นในรายการนี้ทันที ติดตามความคืบหน้าได้จากหน้าเดียวกันตลอด

## T07 ขอย้ายออก

หน้ายื่นคำร้องขอย้ายออกจากห้องที่พักอยู่

### วิธียื่นคำร้องขอย้ายออก

1. เข้าเมนู **ขอย้ายออก**
2. เลือก **วันที่ต้องการย้ายออก** (แนะนำแจ้งล่วงหน้าอย่างน้อย 30 วัน เผื่อเวลาให้แอดมินจัดการ)
3. กรอก **เหตุผล** ที่ต้องการย้ายออก
4. กดส่งคำร้อง

✅ คำร้องเข้าคิวรอแอดมินพิจารณา — ติดตามผลการอนุมัติได้ในหน้าเดียวกันนี้ตลอด

> ⚠️ ยื่นคำร้องใหม่ไม่ได้ถ้ามีคำร้องเดิมที่ยังรอแอดมินพิจารณาอยู่ (ต้องรอผลคำร้องเดิมก่อน)

## T08 ประกาศ/แจ้งเตือน

ฟีดข่าวสารจากแอดมินและการแจ้งเตือนของระบบ (เช่น มีบิลใหม่ออก มีความคืบหน้าเรื่องแจ้งซ่อม) เป็นหน้าดูอย่างเดียว ไม่มีอะไรให้กรอก — ประกาศที่แอดมินปักหมุดหรือทำเป็นเรื่องฉุกเฉินจะถูกเน้นสีให้เห็นชัดกว่ารายการอื่น

## T09 โปรไฟล์

หน้าแก้ไขข้อมูลส่วนตัว เปลี่ยนรหัสผ่าน และเชื่อมต่อ Telegram

### วิธีเชื่อมต่อ Telegram เพื่อรับแจ้งเตือน

1. เข้าเมนู **โปรไฟล์** แล้วหาส่วน Telegram
2. กด **เชื่อมต่อ**
3. ทำตามขั้นตอนที่ระบบแนะนำเพื่อผูกบัญชี Telegram ของตัวเองเข้ากับบัญชีในระบบ

✅ เชื่อมสำเร็จแล้วจะได้รับแจ้งเตือนบิลใหม่และความคืบหน้าแจ้งซ่อมทาง Telegram โดยตรงบนมือถือ — จะยกเลิกการเชื่อมต่อเมื่อไหร่ก็กดปุ่มเดียวกันได้ทุกเมื่อ

### วิธีเปลี่ยนรหัสผ่านของตัวเอง

1. ในหน้าโปรไฟล์ หาส่วนเปลี่ยนรหัสผ่าน
2. กรอกรหัสผ่านเดิม รหัสผ่านใหม่ และยืนยันรหัสผ่านใหม่
3. กดบันทึก

# คำถามที่พบบ่อย

**ลืมรหัสผ่านทำยังไง?**
กด "ลืมรหัสผ่าน?" ที่หน้าเข้าสู่ระบบ ดูขั้นตอนเต็มได้ที่หัวข้อ [ลืมรหัสผ่านทำอย่างไร](#ลืมรหัสผ่านทำอย่างไร)

**(แอดมิน) ทำไมออกบิลไม่ได้?**
เกิดจาก 1 ใน 3 สาเหตุนี้เสมอ: ห้องนั้นยังไม่ได้ทำสัญญาเช่า, ยังไม่ได้บันทึกเลขมิเตอร์ของเดือนนั้น, หรือออกบิลของเดือนนั้นไปแล้วก่อนหน้า — ไปเช็คที่เมนู [บันทึกมิเตอร์](#a06-บันทึกมิเตอร์) ก่อนเสมอ

**(แอดมิน) ทำไมสร้างสัญญาเช่าใหม่ไม่ได้ ห้องไม่ขึ้นให้เลือก?**
ห้องที่มีคนอยู่แล้วจะไม่ขึ้นในช่องเลือกห้องตอนสร้างสัญญา ต้องยกเลิกสัญญาเดิมของห้องนั้นก่อนที่เมนู [สัญญาเช่า](#a04-สัญญาเช่า) ห้องถึงจะกลับมาว่างให้เลือกได้

**(ผู้เช่า) จ่ายเงินแล้ว ทำไมบิลยังไม่ขึ้นว่า "ชำระแล้ว"?**
ระบบไม่ได้ปิดบิลอัตโนมัติทันทีที่แจ้งชำระเงิน ต้องรอแอดมินตรวจสอบสลิปแล้วกดยืนยันก่อนเสมอ ระหว่างนั้นจะเห็นสถานะเป็น "รอตรวจสอบ" ไปก่อน ถ้ารอนานผิดปกติให้ติดต่อแอดมินโดยตรง

**(ผู้เช่า) ไม่มี Telegram หรือไม่อยากเชื่อมต่อ ต้องทำไหม?**
ไม่บังคับ ไม่เชื่อมก็ใช้งานระบบได้ปกติทุกอย่าง แค่จะไม่ได้รับข้อความแจ้งเตือนอัตโนมัติผ่านมือถือเท่านั้น ยังเข้าเว็บมาเช็คเองได้เสมอ

**เข้าเว็บไม่ได้ หรือขึ้นข้อความ error ต้องทำยังไง?**
ก่อนอื่นเช็คว่าอินเทอร์เน็ตใช้งานได้ปกติ แล้วลองตรวจสอบว่าพิมพ์เบอร์โทร/อีเมลและรหัสผ่านถูกต้องหรือไม่ (ระวังตัวพิมพ์เล็ก-ใหญ่ของรหัสผ่าน) ถ้ายังเข้าไม่ได้ให้ลองใช้ "ลืมรหัสผ่าน?" ตั้งรหัสผ่านใหม่ หรือติดต่อแอดมิน/ผู้ดูแลระบบโดยตรง

**เลขบัตรประชาชนหรือข้อมูลส่วนตัวที่กรอกไว้ปลอดภัยไหม?**
ข้อมูลอ่อนไหวอย่างเลขบัตรประชาชนจะแสดงแบบปิดบางส่วนในตารางเสมอ (ไม่โชว์เต็มเลข) และมีเฉพาะแอดมินเท่านั้นที่เข้าถึงข้อมูลผู้เช่าคนอื่นได้ ผู้เช่าแต่ละคนเห็นได้เฉพาะข้อมูลของตัวเองเท่านั้น
